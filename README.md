# Bank Management System

A desktop-based Bank Management System developed using Java Swing and MySQL.

## Features

- User Registration
- User Login
- Account Creation
- Deposit Money
- Withdraw Money
- Fast Cash
- Balance Enquiry
- PIN Change
- Mini Statement

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- JCalendar
